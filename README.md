# ScriptGlyph assets

Public copies of the ScriptGlyph symbol, for places that need an image at a public address: Google Workspace add-on
logos, Google Chat app avatars, web app favicons and Marketplace listings.

## Current: the Branch symbol (brand v3)

The full v3 kit, with lockups, wordmarks, icons and guidelines, is in the ScriptGlyph repository under `brand/v3/`.

- `branch/branch.svg` and `branch-16.png` to `branch-512.png`: the symbol in colour, for light backgrounds. Generated
  add-ons use `branch-128.png` as their logo, and Chat apps `branch-256.png` as their avatar.
- `branch/branch-on-dark.svg`: the symbol for dark backgrounds.

## Earlier: the connected-node icon (brand v2)

Kept so add-ons deployed before v3 keep their logo. Do not use it for anything new. The `c-mark` folder and `C-` file
names keep the icon's working name from the brand pack.

- `c-mark/C-flat-*.png` and `C-flat.svg`: Glyph Blue, for 16 to 24 px on light backgrounds.
- `c-mark/C-reverse-*.png` and `C-reverse.svg`: Ice Blue, for 16 to 24 px on dark backgrounds.
- `c-mark/C-tonal-*.png` and `C-tonal.svg`: from 32 px up on light backgrounds.
- `c-mark/C-tonal-dark-*.png` and `C-tonal-dark.svg`: from 32 px up on dark backgrounds.
